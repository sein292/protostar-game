원시별 키우기 — 내가 모은 질량이 결정하는 별의 일생

고등학교 지구과학 '별의 진화' 단원용 웹 게임입니다. 학생이 성운 속 원시별이 되어 물질을 모으고, 모은 질량에 따라 별이 주계열성을 거쳐 갈색왜성·적색왜성·백색왜성·중성자별·블랙홀 중 하나로 진화하는 과정을 H-R도 궤적과 함께 확인합니다.

실행: index.html 파일 하나로 동작하며, 설치가 필요 없습니다. 브라우저에서 열거나 GitHub Pages 주소로 접속하세요.
대상: 고등학생 (4차시, 4인 모둠)
관련 성취기준: 2022 개정 과학과 교육과정 지구과학 '별의 진화' 관련 성취기준

모델과 데이터 (현재 버전)
주계열 광도·반지름: 질량–광도 관계(L ∝ M^2.3~3.5)와 질량–반지름 관계로 계산
주계열 수명: 1 M☉ 이하는 t ≈ 100억 년 × (M/M☉)^−2.5, 그 이상은 항성 진화 모델 값에 가깝게 맞춘 대략값 표를 보간
진화 궤적: MIST 등 항성 진화 모델의 모양을 단순화한 교육용 근사
H-R도 배경: Gaia DR3 분포를 흉내 낸 임시 점 (이름이 붙은 별은 문헌의 대략값)
